# Personal Finance Dashboard - Stage 1

This is the first stage of the Personal Finance Dashboard project. It focuses exclusively on building the frontend foundation using core web technologies.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Structure
- `index.html`: The structure of the web page.
- `css/style.css`: The visual design and responsive layout rules.
- `js/app.js`: The interactivity (mobile menu toggle, real-time date insertion).

## How to Run
No complex build tools are required for this stage:
1. Open the `finance-dashboard` folder.
2. Double-click on `index.html` to open it in your web browser (Chrome, Safari, Firefox, Edge).

## Features
- Dashboard Layout with Sidebar and Top Navigation
- Summary Metrics Cards
- Transaction Table History
- Categorized Spending Breakdown
- Responsive layout that adapts to mobile, tablet, and desktop screens.
